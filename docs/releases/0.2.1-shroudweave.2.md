# Shroudweave Shroudtopia 0.2.1-shroudweave.2

Local test candidate. Adds a real process-resident detour service behind the
existing ModContext callback, preserving the SDK ABI. Successful requests return
a trampoline. Duplicate targets, invalid executable images, foreign MinHook
initialization and uncertain failed enables refuse safely. Target, callback and
host images remain pinned until process exit; there is no hot-unload service.

Includes the retained repaired MinHook 1.3.4 implementation and its original BSD
notices. This package does not enable any mod or overwrite personal settings.
Flight/stamina requires its separately pinned, reviewed module and Manager
composition. Offline fixture tests do not establish gameplay or multiplayer
acceptance. Keep publication on hold pending the requested local test.
