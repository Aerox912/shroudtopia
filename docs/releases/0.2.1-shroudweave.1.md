# Shroudweave Shroudtopia 0.2.1-shroudweave.1

Standalone Windows x64 community release of the Shroudtopia compatibility loader. The SDK/API version remains 0.1.1.

## Compatibility change

Compatible with Creative Mode 3.0.0. Shroudtopia now skips Flame-owned and malformed ownership manifests before calling `LoadLibrary` or applying defaults. This keeps Creative Mode on its separate Flame/proxy load path instead of probing it as a Shroudtopia plugin. Native Shroudtopia manifests and supported legacy DLL discovery remain available.

## Validation scope

GitHub Actions builds the native binaries, runs the manifest-discovery regression tests, and packages this release. Minimap visibility, F10 hide/show, north-up positioning and Creative Mode were also tested in-game with this version. Compatibility with every mod combination is not established.

## Install

Close the game and back up any existing `winmm.dll`, `shroudtopia.dll` and `shroudtopia.json` outside the game folder. This release requires both root DLLs: `winmm.dll` (WinMM proxy) and `shroudtopia.dll` (loader). If an existing `winmm.dll` belongs to another loader or mod, retain its backup and resolve proxy compatibility before replacing it.

Extract the standalone archive into the Enshrouded game folder. It updates the DLLs and leaves an existing `shroudtopia.json` untouched. Preserve your settings and enabled mod list.

Only if no `shroudtopia.json` exists, copy `examples/shroudtopia.default.json` to the game folder as `shroudtopia.json`. The example has an empty `mods` object. Never copy it over an existing configuration during an upgrade.

Minimap remains a separate ZIP, installed into the same game folder under `mods/minimap_mod`. This Shroudtopia archive does not include Minimap or Creative Mode.
