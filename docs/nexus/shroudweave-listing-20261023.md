# Nexus listing

## Title

Shroudtopia 'Shroudweave' - 1.0 Compatible

## Short summary

A maintained Shroudtopia fork for mods supported by the current release.

## Listing description

This fork loads and runs mods built for compatible Shroudtopia releases. It is based on the [original Shroudtopia project](https://github.com/s0t7x/shroudtopia), credited to Miguel Oppermann (s0T7x) and licensed under MIT. I maintain this fork under MIT; I did not author or claim ownership of the original code. See the [maintained source](https://github.com/Aerox912/shroudtopia) and [MIT license](https://github.com/Aerox912/shroudtopia/blob/main/LICENSE). The current public fork release is [0.2.1-shroudweave.1](https://github.com/Aerox912/shroudtopia/releases). Check its release notes for supported game builds and mods.

1. Download the [Main file on this page](https://www.nexusmods.com/enshrouded/mods/216).
2. Extract the release files into your Enshrouded game folder.
3. When upgrading, keep your existing `shroudtopia.json` and settings; back them up before replacing loader files.
