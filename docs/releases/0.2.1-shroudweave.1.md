# Shroudweave Shroudtopia 0.2.1-shroudweave.1

Standalone Windows x64 community release of the Shroudtopia compatibility loader. The SDK/API version remains 0.1.1.

## Compatibility change

Shroudtopia now skips Flame-owned and malformed ownership manifests before calling `LoadLibrary` or applying defaults. This keeps Flame-owned Creative 3.0.0 on its explicit proxy load path instead of probing it as a Shroudtopia plugin. Native Shroudtopia manifests and supported legacy DLL discovery remain available.

## Validation scope

GitHub Actions builds the native binaries, runs the manifest-discovery regression tests, and packages this release. Those checks verify build and discovery behavior; they do not establish gameplay compatibility, FPS improvement, or runtime coexistence with every mod.

## Install

Extract the standalone archive into the Enshrouded game folder. It includes the WinMM proxy, Shroudtopia loader, and default `shroudtopia.json` with an empty mod list. Preserve a backup if the game folder already has `winmm.dll` or `shroudtopia.json` before replacing either file.

The standalone Minimap ZIP remains a separate download. An optional combined Minimap + Shroudtopia ZIP is also provided for one-step extraction into the game folder.
